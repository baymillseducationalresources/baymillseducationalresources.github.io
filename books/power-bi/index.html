How to download and extract your files

  1. Find the project number matching the chapter you are working on.
  2. Click its Download Project ZIP link.
  3. Save the ZIP file to your computer, preferably in Downloads.
  4. Open File Explorer and find the downloaded ZIP file.
  5. Right-click the ZIP file and select Extract All.
  6. Choose an extraction location and click Extract.
  7. Open the extracted folder to find the project files and practice datasets.
  8. Follow your book chapter's instructions for opening the .pbip project in Power BI Desktop, configuring the DataFolder or file paths, and refreshing the data where required.

Important: Extract the ZIP before opening the Power BI project. Some projects require path configuration or data refresh before their visuals display correctly.
