Download help

Download a resource ZIP

Open your book’s resource page and select the download link when one is available. Your browser will usually save the ZIP file in your Downloads folder.

Extract files on Windows

Open File Explorer, choose Downloads, right-click the ZIP file, select Extract All, and then select Extract. Open the new extracted folder to find your learning materials.

Use the resources

Read the START_HERE instructions included in the downloaded package. Use the book’s exercises for guidance on opening files in the relevant application.

Having trouble?

If a ZIP will not open, delete the incomplete download and download it again. Make sure you are opening the extracted folder, not just previewing the ZIP archive.
